# Voltrune Theme Collection

Voltrune e uma colecao de temas escuros premium para VS Code, com identidade elegante, foco em legibilidade prolongada e variacoes visuais consistentes para diferentes estilos de trabalho.

## Preview

![Preview da colecao Voltrune](https://via.placeholder.com/1200x700.png?text=Voltrune+Theme+Collection)

## Temas Disponiveis

- Voltrune Obsidian: dark premium, contraste suave e conforto para longas sessoes.
- Voltrune Eclipse: atmosfera noturna com base azul escuro e roxos suaves.
- Voltrune Ember: dark energetico com acentos quentes em amber, cobre e dourado suave.
- Voltrune Frost: visual frio, tecnico e limpo com azul petroleo, cinza frio e ciano suave.
- Voltrune Arcane: personalidade mistica com roxos suaves e azuis vivos controlados.
- Voltrune Nocturne: dark plus com base quase preta, prata suave, bronze, dourado e azul mistico controlado.

## Features

- Colecao com seis temas dark prontos para alternancia local ou publicacao.
- Profundidade visual inspirada em glassmorphism simulado, sem depender de blur real.
- Paletas suaves e equilibradas para reduzir fadiga visual.
- Contraste otimizado para produtividade em uso prolongado.
- Excelente experiencia para JavaScript, TypeScript, PHP, HTML, CSS/SCSS e JSON.
- Semantic tokens configurados para consistencia com linguagens modernas.

## Instalacao (modo desenvolvimento)

1. Clone este repositorio.
2. Abra a pasta no VS Code.
3. Pressione F5 para iniciar uma janela Extension Development Host.
4. Na nova janela, abra o seletor de tema e escolha qualquer variante Voltrune disponivel.
